# 📺 Luigie Martin — Retro Pixelated CRT TV Portfolio

An immersive, nostalgic, and clean personal web portfolio showcasing the engineering projects, technical skills, and academic journey of **Luigie Martin** ([@dxlmartin00](https://github.com/dxlmartin00)), fresh graduate in Computer Science from **North Eastern Mindanao State University (NEMSU - Lianga Campus)**.

Built with an authentic **1990s Cathode Ray Tube (CRT) Television** aesthetic and navigated via a **handheld infrared remote control**.

---

## ✨ Features

### 📺 Vintage CRT Television Simulation
- **Initial Shut-Off Standby Experience**: Upon landing, the TV sits dormant in standby with dark curved CRT glass, pulsing power heartbeat LED, and a retro radar prompt.
- **Scroll-Triggered Ignition**: Scrolling down triggers cathode ray electron beam warm-up, degauss thump, and white noise burst to ignite the display.
- **Authentic CRT Shaders & Scanlines**: Interlaced phosphor scanline overlay, subpixel RGB grid, curved screen glass glare, and realistic cathode ray tube vignette.
- **Dynamic TV Static / White Noise**: High-performance HTML5 Canvas procedural pixel snow generator triggered on every channel transition and scroll.
- **Cathode Ray Power-Off/On**: Authentic CRT electron beam collapse animation when powering down or turning on.
- **Retro On-Screen Display (OSD)**: Bright green phosphor HUD showing active channel, tuning status, volume bars, and audio mode.
- **Physical Controls**: Interactive rotary channel selector dial and power switch directly on the television casing.

### 🎮 Handheld Infrared Remote Control
- **Smooth Diagonal Entrance**: As you scroll, the handheld remote swoops in diagonally from the bottom-right with weighted spring physics and an IR transmission chirp upon locking in place.
- **Red Power Button**: Turns the TV on and off with screen collapse and degauss audio.
- **Number Pad (1 to 6)**: Direct channel jump to any section.
- **CH +/- & VOL +/- Rockers**: Sequential channel surfing and volume control.
- **D-Pad & OK**: Navigate project cards and interact with the Easter egg arcade game.
- **GUIDE / MENU Button**: Opens an on-screen retro TV Broadcast Directory schedule overlay.
- **4 CRT Phosphor Color Buttons**:
  - 🔴 **Cyberpunk RGB**: Vibrant multi-phosphor colors with chromatic edge.
  - 🟠 **Amber Monochrome**: 1980s warm amber terminal phosphor.
  - 🟢 **Matrix Green**: Classic P1 green phosphor CRT monitor.
  - ⚪ **Classic B&W**: 1960s black-and-white vacuum tube television.
- **Mobile Responsive Drawer**: Thumb-friendly bottom dock drawer and floating pill trigger for mobile devices.

### 🔊 Procedural Web Audio Engine
- **Zero External Audio Assets**: 100% synthesized in real time via the browser's Web Audio API (`AudioContext`).
- **Tactile Sounds**:
  - Mechanical micro-switch button clicks.
  - Bandpass-filtered white noise static bursts.
  - CRT power-up degauss drone and power-down collapse tone.
  - 8-bit square-wave volume pips and channel notification chimes.

## 🚀 Getting Started

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it in Chrome, Firefox, Safari, or Edge. No compilation or dependencies required!

### Option 2: Run Local Server (Node.js)
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⌨️ Keyboard Shortcuts

- **`1` - `6`**: Jump directly to Channel 1 through 6
- **`▲` / `▼` (Arrow Keys)**: Channel surfing / Arcade paddle control
- **`P`**: Power TV On / Off
- **`M`**: Mute / Unmute audio
- **`G`**: Open TV Guide directory
- **`T`**: Cycle CRT phosphor color themes

---

## 🌐 Deploy to GitHub Pages / Vercel

Since this project uses zero-dependency vanilla HTML5, CSS3, and ES6+ JavaScript, deploying is instant:
- **GitHub Pages**: Go to repository Settings > Pages > Select `main` branch and `/` root folder > Save.
- **Vercel / Netlify**: Connect repository or drag-and-drop the folder for instant global deployment.
